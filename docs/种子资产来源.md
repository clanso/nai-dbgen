# 种子资产来源

本文记录 `assets/seed/` 各文件从本地应用 `app/` 的哪一段抽出、改编了什么、为何改编。
对照需求：`docs/酒馆数据库生图插件需求.md` §4.2 / §4.4 / §4.11 与步骤四、五。

---

## 1. `preset-imagegen.json`（生图预设 · 步骤五）

| 项 | 内容 |
| --- | --- |
| 主要来源 | `app/public/assistant.js` L17–31（`OUTPUT_STRUCTURE_RULE` + `modelPromptInstruction`）、L986（`NO_CHARACTER_DNA_CONSTRAINT`） |
| 次要参考 | `app/public/tavern-engine.js` L235–252（`assembleMessagePreset` 的 `worldInfo` / `historyContext` 占位思路）；需求文档 L369–469（slot JSON 形状） |
| 未采用 | `app/public/comic-mode.js` L127–161 漫画分镜提示词（输出 `<image>` / panel，与 slot caption 契约无关） |

### 改编了什么

1. **输出格式**：桌面助手要求 `image###...###` + Scene/Char/UC 文本。插件让模型写扁平字段（`slotid` / `scene` / `scene_uc` / `char` / `char_uc`），由程序套成 `v4_prompt` / `v4_negative_prompt`。以 `flat-imagegen.js` 为准。
2. **变量**：桌面用酒馆 marker（`worldInfoBefore` / `chatHistory`）或 `{{worldInfo}}`；插件四块是 `{{世界书}}` / `{{当前上下文}}` / `{{角色库}}` / `{{标签库}}`（见 `variable-map.js`）。
3. **DNA**：桌面强制先输出「角色 DNA（锁定版）」；插件角色外观已由「角色库」注入块提供，故并入 `NO_CHARACTER_DNA_CONSTRAINT` 精神——禁止再输出 DNA 散文。
4. **画师串**：桌面可在提示词侧混风格；插件画师串由 4.14 出图时拼接，种子预设明确禁止写入画师串。

### 固定 id

`seed-preset-imagegen-v1`

## 2. `preset-recall.json`（召回预设 · 步骤四）

| 项 | 内容 |
| --- | --- |
| 主要来源 | **无。** 在 `app/public/` 全文检索未发现「只传 key、回 key 列表」的标签召回 LLM 提示词 |
| 契约来源 | 需求 §4.11；`tag-recall.service.js` 注入 `{{当前上下文}}` + `{{候选 key}}`；`RECALL_KEYS_JSON_SCHEMA` / `extractRecalledKeyList` / `reconcileRecalledKeys` |

### 为何仍交付

没有上游调试过的召回文案可抄。交付的是**按插件契约拼装的最小指令模板**（只说明输入两块、输出 JSON 字符串数组、必须原文回 key），不是创意性「发明」业务策略。报告中单独标出，便于日后用真实对话效果替换。

### 固定 id

`seed-preset-recall-v1`

## 3. `artists.json`（画师串种子库）

| 项 | 内容 |
| --- | --- |
| 来源 | `app/public/builtin-styles.json` |
| 现状 | `version: 9`，`entries: []`（空）。`docs/整体架构设计.md` §7 写明「空白分发」 |
| 转换 | 信封 `kind: "artist"`，`items: []`。空库可过导入校验，不写入任何画师串 |

**诚实结论**：当前仓库没有可转成 `ArtistString` 的预置画风串数据。用户需自行导入或在面板新建。未从 `app.js` 首页占位提示词或其它文件编造画师串。

## 6. 加载器行为（`src/bootstrap/seed.js`）

- 首次 `activate` 后调用 `installSeedAssets`
- 账本双写：`localStorage[nai-dbgen:seed-ledger-v1]` + `extensionSettings['nai-dbgen-seed-ledger']`（不进 PluginSettings，避免 D8）
- 已登记 id：跳过；已存在同 id：登记并跳过（**永不 overwrite**）
- 用户删除后：账本仍在 → **不复活**
- 异常只 `log.warn`，不阻断启动
- 若 `activeImagegenPresetId` / `activeRecallPresetId` 为空，自动指向种子预设
