# 应用层接口交接（W2-F → UI 层与 W3 装配）

W2-F 已完成 `src/application/**`，238 项测试全绿。本文是**唯一权威**的接线依据。
UI 层与装配层照此写，字段名写错一个就装不起来。

> UI 层**不得**自己 `import` 应用层以外的东西去凑功能。
> 缺能力 → 写「契约变更申请」交协调者裁决，不要绕过。

---

## 1. UI 层能调的对外方法

| 方法 | 入参要点 | `Ok` value |
| --- | --- | --- |
| `generateSlots.execute(messageId, opts?)` | `opts: { signal?, traceId? }` | `{ records, traceId, llmCallCount, unmatchedKeys }` |
| `renderSlot.execute(messageId, slotId, opts?)` | 同上 | `{ record, image, traceId }` |
| `imageGen.generate(req)` | **`req.replaceCharacterKeywords` 必填 boolean** | `GeneratedImage[]` |
| `workbench.writePrompt(input)` | 不出图、不改替换开关 | `{ caption: NaiCaption, unmatchedKeys }` |
| `workbench.generateImage(input)` | `replaceCharacterKeywords` 必填 | `GeneratedImage[]` |
| `artistPreview.preview(input)` | 传**正在编辑的那一条**画师串 | `{ image, imageRef? }` |
| `tagRecall.recall(input)` | — | `{ matched, unmatched }` |
| `autoTrigger.start()` / `.stop()` | — | `void` |

全部返回 `Result`，**不抛异常**。失败取 `err.message`（已保证是中文面向用户文案）直接进 toast。

### 三条硬规矩

1. **`replaceCharacterKeywords` 是必填入参，程序绝不推断。**
   验收 #13 要求：用户把自动生成的提示词改成手填、或改了一半，这一档也不能由程序替他决定。
   UI 上必须有明确控件，其值直接透传。
2. **`unmatchedKeys` 必须让用户看见。** 需求 4.11 与验收 #2 要求可观测。
   LLM 股造或拼错的 key 静默丢弃 = 用户拿到一张少了标签的图却不知道为什么。
3. **画师预览尺寸固定 `ARTIST_PREVIEW_SIZE`（832×1216），禁止魔法数。**

## 2. Bus 事件（`APP_EVENTS`，导出自 `src/application/_helpers.js`）

| 事件名 | 何时 | 载荷 |
| --- | --- | --- |
| `slots:written` | 生图链路落盘成功 | `{ messageId, records, traceId, llmCallCount, unmatchedKeys, placements? }` |
| `slot:rendered` | 单个 slot 出图成功 | `{ messageId, slotId, imageRef, traceId, record }` |
| `tag-recall:unmatched` | 召回有未命中 | `{ messageId, traceId, unmatchedKeys, matchedCount }` |

slot 控件订阅 `slot:rendered` 刷新自己；toast 订阅 `tag-recall:unmatched`。
**事件名用 `APP_EVENTS` 常量，不要写字面量字符串**——拼错不报错，只是永远收不到。

## 3. deps 形状（W3 装配用）

装配时注意三处**同实例**要求，写错不报错但行为会错：

- `llm`：`tagRecall` 与 `generateSlots` 必须同一实例（LLM 调用计数依赖同引用）
- `tagRecall`：`generateSlots` 与 `workbench` 必须同一实例（D33）
- `bus`：`generateSlots`、`renderSlot`、`autoTrigger` 必须同一个（D32 事件驱动依赖此）

| 工厂 | 必填 deps |
| --- | --- |
| `createContextCollector` | `host`, `loadSettings` |
| `createWorldInfoResolver` | `host` |
| `createTagRecallService` | `llm`, `tagRepo`, `presetRepo`, `llmConfigRepo`, `loadSettings`, `runHostMacros` |
| `createGenerateSlotsUseCase` | `host`, `llm`, `characterRepo`, `tagRepo`, `presetRepo`, `slotRepo`, `llmConfigRepo`, `contextCollector`, `worldInfoResolver`, `tagRecall`, `bus`, `loadSettings`, `runHostMacros`, `newId`, `nowIso`, `newTraceId` |
| `createImageGenService` | `imageGenPort`, `artistRepo`, `naiConfigRepo`, `loadSettings`, `newTraceId`；`characterRepo` 在 `replaceCharacterKeywords===true` 时必需 |
| `createRenderSlotUseCase` | `imageGen`, `slotRepo`, `imageRepo`, `bus`, `nowIso`, `newTraceId` |
| `createArtistPreviewService` | `imageGen`, `artistRepo`, `imageRepo` |
| `createWorkbenchService` | `llm`, `imageGen`, `characterRepo`, `tagRepo`, `llmConfigRepo`, `tagRecall`, `loadSettings`, `runHostMacros`；`presetRepo` 可选 |
| `createAutoTriggerService` | `host`, `generateSlots`, `renderSlot`, `slotRepo`, `loadSettings`, `bus` |

## 4. 降级语义（UI 要照此显示状态）

链路是**部分失败可降级**的，不要把降级当成失败弹红：

| 失败点 | 行为 | UI 该怎么显示 |
| --- | --- | --- |
| 世界书取不到 | 降级为空块，继续出图 | 可提示「世界书未参与」，不算错误 |
| 角色库取不到 | 降级为空块 | 同上 |
| 标签召回失败/未配 | 降级为空块 | 同上 |
| 提示词 LLM 失败 | **短路 Err** | 红色错误，展示 `err.message` 与 `traceId` |
| 改正文 / 写盘失败 | **短路 Err** | 同上 |
| NAI 出图失败 | **短路 Err** | slot 控件内显示错误 + 重试入口 |
| 用户取消（Abort） | **短路，不重试** | 恢复初始态，**不要弹错误** |
