# 生成工作台：画师串选择与状态位置调整

日期：2026-09-27

改动标题：工作台复用画师串选择器并调整状态显示位置

## 需求与行为

1. 在生成工作台“出图 / 取消出图”右侧增加“当前画师串”选择器。
2. 复用设置面板的 `mountCurrentPicker`，保留封面、名称搜索、当前项高亮、切换与清除功能。
3. 与设置面板共用 `activeArtistId`。任一入口的切换或清除都会同步；不是独立的工作台画师配置。
4. 画师库内容更新时刷新候选项和封面；粘贴提示词匹配画师后立即刷新当前项。
5. 将原工作台顶部状态移至“写提示词 / 取消”旁，沿用原有状态组件及任务状态逻辑。
6. 窄屏下选择器自动换行。工作台的候选列表向上展开，并限制高度，避免被底部弹窗边界裁切；设置面板的展开方向不变。
7. 关闭工作台弹窗时销毁组件，释放设置订阅、画师库订阅、回退轮询与选择器监听。

## 使用与手工复查

1. 更新文件后，在酒馆页面按 `Ctrl+F5` 强制刷新，再打开生成工作台。
2. 检查“出图”旁的画师选择器是否与设置面板显示相同当前项。
3. 搜索并切换画师、清除选择，再回到设置面板确认同步；反向操作后重开工作台确认同步。
4. 粘贴含库中已有画师串的提示词，确认当前画师自动更新。
5. 确认“空闲”等状态显示在“写提示词 / 取消”附近，工作台顶部不再重复显示。
6. 在窄屏检查候选列表向上展开、可滚动选择，关闭并重开工作台仍正常。
